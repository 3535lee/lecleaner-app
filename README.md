# LeCleaner

Official **MacLee LeCleaner** installation and update distribution repository.

LeCleaner is a proprietary, closed-source macOS application. Its development
source is private and is not published in this repository.

## Downloads

Verified native Swift releases will appear in [Releases](https://github.com/3535lee/lecleaner-app/releases).
No installation or update binary has been published yet.

Release assets contain the installer, signed update archive, checksums, and
release notes. The app's signed updates use the Sparkle appcast in this repository.
Do not install files from unrelated repositories or unofficial mirrors.
